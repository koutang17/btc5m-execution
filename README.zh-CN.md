# BTC 5 分钟预测市场执行系统

币安 Predict「BTC 涨跌 5 分钟」市场的自动化交易系统，个人独立开发并 7×24 运行在 Windows 主机上。

> **状态：快照。** 本仓库是实盘系统的脱敏快照，用于架构展示与作品集。
> **不构成投资建议，也不能直接运行**：密钥、账户数据、订单历史与行情数据已移除。
> 硬化改造进度见 [docs/roadmap.md](docs/roadmap.md)。

## 它做什么

每 5 分钟：拉取**已收盘**的 K 线 → 识别连续同向根数 → 查该档历史反转概率 →
按分数凯利对实时盘口定价 → 在当期 UP/DOWN token 上挂限价单 → 等轮次结束后
按严格优先级判定胜负 → 赎回 → 记录 → 推送通知。

双账户物理隔离（独立钱包会话、状态文件、配置），另有 Web 看板与三类守护进程
（进程 / 登录 / 网络）。

## 这个项目真正解决的工程问题

- **会话型钱包登录**：交易通道是扫码登录的钱包 CLI 而非 API Key，必须区分
  「会话过期」与「网络故障」，否则一次网络抖动就会把机器人踢下线。
- **限价未成交是信息**：首单未成交通常意味着价格朝有利方向走了，记 SKIP 而非亏损，也不追下一轮。
- **结算字段不稳定**：`result` 可能为空、`isWinner` 可能缺失，按
  `WIN/LOSS → isWinner → pnl 符号 → canClaim` 的严格优先级解析，绝不默认判输。
- **部分成交**：`filledShareQty > 0` 不等于全部成交，残留挂单的处理在风险清单里。
- **可恢复**：每次状态迁移落盘，重启后能续上未结算的轮次，避免重复下单。

## 已验证 / 未验证

**代码层面已确认**：只用已收盘 K 线、结算优先级链、硬止损 fail-closed、双账户隔离、
回测显式建模成交假设（`always / adverse / random / hybrid`）。

**未验证**：策略是否具有正期望。概率表是 90 天样本内估计，实盘样本过小，
扣费后的盈亏平衡点与估计值过近，无法拒绝「零 edge」假设。具体收益数字不在仓库中展示。
