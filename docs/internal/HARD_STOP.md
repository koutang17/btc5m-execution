# 硬止损说明

每个账户独立配置，位于看板“参数设置”：

- 硬止损方式
  - 关闭
  - 最大回撤(u)
  - 连续亏损周期
- 最大回撤(u)
- 最多连续亏损周期

## 最大回撤
从策略累计盈亏的历史最高点计算：

    当前回撤 = 历史最高累计盈亏 - 当前累计盈亏

达到设定值后：

- 写 PAUSE 标记
- 暂停该账户的新开单
- 发企业微信通知
- 看板显示“硬止损已触发”

单位是 u，不是百分比。

## 连续亏损周期
只统计真正完成的亏损马丁周期：

- 5次亏损止损结束的周期算一个
- 首单未成交的 ABORT 不算
- 盈利周期把连续亏损计数清零

达到设定个数后暂停该账户。

## 恢复
硬止损触发后，直接点“继续”通常还会再次暂停，因为条件仍然存在。

要恢复，需要：

1. 提高最大回撤阈值
2. 或提高连续亏损周期数
3. 或关闭硬止损
4. 再点“继续”

如果只想临时恢复，不建议关闭硬止损后忘记重新打开。
